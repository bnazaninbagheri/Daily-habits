# Daily habits | عادت های روزانه

## معرفی محصول

Daily habits یک برنامه برای ثبت و پیگیری عادت‌های روزانه است که به کاربران کمک می‌کند عادت‌های خود را مدیریت کنند، برای انجام آن‌ها یادآور داشته باشند و میزان پیشرفتشان را مشاهده کنند.

## مسئله و نیاز کاربران

بسیاری از افراد انجام عادت‌های روزانه را فراموش می‌کنند یا نمی‌توانند میزان پیشرفت خود را بررسی کنند. این برنامه به آن‌ها کمک می‌کند عادت‌های خود را منظم‌تر دنبال کنند.

## ویژگی‌های اصلی

*  مدیریت عادت‌های روزانه
* ثبت انجام شدن یا نشدن هر عادت
* یادآوری انجام عادت‌ها
* نمایش آمار روزانه و هفتگی
* مشاهده سابقه عادت‌ها
* نمایش میزان پیشرفت

## مخاطبان محصول

* دانش‌آموزان و دانشجویان
* افرادی که قصد ایجاد عادت‌های مفید دارند
* افرادی که می‌خواهند سبک زندگی خود را منظم‌تر مدیریت کنند.
